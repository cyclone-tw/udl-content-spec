# examples

合成範例內容包（CC-BY 4.0，見 `../LICENSE-CONTENT.md`）。不含課文原句、不含學生資料；文本原創，只對齊教科書進度。

- `minimal/`：一個國語單元（原創短文、對話、選擇／是非／配對各一題、一個語意混淆池）＋一個數學小單元（情境示範、固定計算題、參數化題「二位數進位加法」）。語音槽皆為 `null`，驗證時會警告。另有一題聽音選字（#36，`items/i-listen-01.json`）與它用到的三張生字卡（行、星、走，給同音字檢查查讀音）；`audio/xing2.m4a` 是 0.4 秒的**靜音佔位檔**，只為了讓 `files` 有真的 sha256，不是語音成品。另有一題修辭選擇題（#43，`items/i-rhetoric-01.json`，原創句「月亮像一艘小船，掛在天上。」）：兩個錯誤選項各標錯誤類型並帶逐選項回饋，代碼表在 `pack.json` 的 `misconceptions`。
- `cards-demo/`（#31）：卡片庫與綁卡單元——三張生字卡（含易混淆字）、四張語詞卡（含例句）、一張句型卡、一張數學技能卡；國語單元綁卡並附心智圖教材，數學單元綁技能卡與示範教材。`planSteps` 依年級設定排出關卡，練習與測驗由卡片生題。
- `scopes/first-lesson-test.json`：Scope 範例「只從第一課出題」。

改動範例後執行 `pnpm run update-files examples/<包>` 更新 hash。
